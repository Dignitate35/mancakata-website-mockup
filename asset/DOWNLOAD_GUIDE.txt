🚀 CARA PAKAI:

Opsi A - Standalone (PALING MUDAH):
1. Download "Mancakata-Standalone.html"
2. Buka di browser (Chrome, Firefox, Safari, Edge)
3. Selesai! Klik Tweaks panel, explore semua halaman & CMS

Opsi B - Untuk GitHub/Vercel:
1. Download semua files di atas
2. Buat folder: "mancakata-website-design"
3. Masukkan semua files ke folder
4. Push ke GitHub
5. Deploy ke Vercel

Opsi C - Manual Copy-Paste:
1. Buka tiap file HTML di sini
2. Copy isi
3. Paste ke text editor (VS Code, Sublime, dll)
4. Save dengan nama yang sama
5. Repeat untuk semua files
